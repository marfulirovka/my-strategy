# my-strategy — личный стратегический дом

База данных интеллектуальной работы: знания, решения, задачи, заметки. Код и скрипты здесь не хранятся (для них отдельные DS-репозитории).

## Маршрутизация записей

| Тип ввода | Куда |
|---|---|
| Быстрая заметка, идея, захват | `inbox/fleeting-notes.md` |
| Знание, решение, задача, план РП по проекту | папка проекта (`okc/`, `disser/`) + журнал решений в ней |
| Формализованное знание о предмете | `PACK-platform-medicine` (дом Pack) |
| Контакт / устойчивый факт о себе | PD-persona — не подключён, не пишем |
| Еда / здоровье / рефлексия / саморазвитие | PD-metrics — не подключён, по ситуации фиксируем в `inbox/` |

## Структура

- `inbox/` — входящие заметки, захваченные идеи
- `okc/` — проект «Модельный общественно-культурный центр»
- `disser/` — трек диссертации (артефакты текста, решения, план)
- папки проектов добавляются по мере появления

## Журнал входов

Отсутствует (нет выделенного репозитория журнала с объявленной ролью) — отдельный след по записям не ведётся.
